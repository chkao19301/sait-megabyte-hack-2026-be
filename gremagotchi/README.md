# 🐹 Gremagotchi (Frontend App)

> Full documentation and screenshots are available at the root [README.md](../README.md).

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Or start with custom port and host
npm run dev -- --port 5050 --host 0.0.0.0

# Build for production
npm run build
```
